# Astro Landing Page

A simple responsive product landing page built with HTML and CSS.

## 🚀 Overview

This project is a static website for an e-commerce-style product page named **Astro**. It includes a top navigation bar, product details section, image display, and product options like size, color, wishlist, and add-to-bag actions.

## 📁 Project Structure

- `index.html` — main page markup
- `style.css` — styling and responsive layout
- `assets/` — images used by the page

## ✨ Features

- Responsive layout for desktop, tablet, and mobile
- Flexible grid layout for product thumbnails
- Clean navigation bar with icon buttons
- Styled product details and selection controls
- Fully static and easy to host

## 🛠️ How to Use

1. Open `index.html` in any web browser.
2. No build tools or server setup required.

## 💡 Notes

- The page uses Font Awesome for icons via CDN.
- The layout adapts at breakpoints for smaller screens.
- Update image files in `assets/` if you want to change product visuals.

## 📌 Recommended Improvements

- Add a mobile menu toggle for small screens
- Convert select boxes to custom dropdowns
- Add hover states and transitions for buttons
- Use more semantic HTML sections for accessibility
